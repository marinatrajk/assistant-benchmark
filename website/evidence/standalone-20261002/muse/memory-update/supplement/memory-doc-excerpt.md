# Native memory documentation — short excerpt

Source: ~/docs/memory.md (the harness's memory documentation), first section,
quoted verbatim:

> # Memory
>
> Memory keeps lasting facts and preferences about the user for future
> conversations. The user can ask in chat to remember, update, or forget
> something. Memory notes can also be written in the background.
> For background upkeep, read `~/docs/self_improvement.md`.
>
> Before saying what is or is not saved, check memory. Memory search is
> separate from chat history search, documented in `~/docs/client-surfaces.md`.

What this establishes: durable memory in this harness is a native, lasting
mechanism for facts and preferences, readable and writable in the normal
course of work ("remember, update, or forget"). The `~/memory/` tree —
including the namespaced benchmark-personas/ file used in this run — is that
established durable store.

No real user memory content is included in this excerpt or anywhere in this
supplement.
