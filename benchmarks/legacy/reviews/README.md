# Historical reviews

`everyday-pilot-20261002.json` preserves the six-task pilot dataset as it appeared before the website switched to individual tasks on October 2, 2026. It includes the earlier portable-suite summary. Its grades are not included in current scores.

Evidence paths in this historical JSON are relative to `website/`, where the previously published files remain. A pending cancellation means the required absence evidence had not been reviewed; an elapsed deadline alone is not a pass. The times in those summaries refer to October 1, 2026.

Current individual results and task coverage are maintained in `website/review.json`.
